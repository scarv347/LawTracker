# LawTrack AI Agent Rules

PROJECT_SPEC.md is the source of truth.

- Read PROJECT_SPEC.md before architectural decisions
- Work one phase at a time
- Show a short plan before major multi-file edits
- Prefer simple hackathon implementations
- Never fabricate laws, citations, cases, URLs, or dates
- Never expose secrets (no secrets in frontend code, no committing .env or secret files)
- Do not automatically commit or push to Git
- Do not migrate frameworks without approval
- Run TypeScript and ESLint checks before declaring a task finished
- Do not add unnecessary dependencies
